# Acoustic Emission Data Analysis

Automated processing and analysis of Acoustic Emission (AE) data from Vallen Systems (`.pridb` and `.tradb` databases).

## Features
* **Feature Extraction:** Calculation of physical features (e.g., Spectral Centroid, Clearance Factor).
* **Signal Processing:** Fast Fourier Transformation (FFT) and frequency analysis.
* **Data Visualization:** Correlation plots for damage detection and condition monitoring.

## Tech Stack
* Python 3
* NumPy / Pandas
* OpenAE
* PyTorch (for upcoming ML tasks)
